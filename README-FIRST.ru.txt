TRAYMETRY

Компактный монитор ресурсов Windows: FPS, температуры, загрузка CPU и GPU,
память, диски и сеть — поверх игры или на втором мониторе.

English version of this file: README-FIRST.txt

Система: 64-битная Windows 10 или 11, процессор Intel или AMD,
.NET Framework 4.7.2 или новее.


КАК ЗАПУСТИТЬ

1. Полностью распакуйте архив в обычную папку.
2. Запустите Traymetry.exe.
3. Windows покажет «Неизвестный издатель». Так и есть: сам исполняемый файл
   не имеет подписи Authenticode. Подписан манифест обновлений — ключом,
   открытая половина которого вкомпилирована в сам EXE, см. раздел
   ОБНОВЛЕНИЯ. Файл SHA256SUMS.txt в этом архиве — хеш вашего Traymetry.exe;
   тот же хеш опубликован вместе с релизом.


ДРАЙВЕР ДАТЧИКОВ, ПРИ ПЕРВОМ ЗАПУСКЕ

Низкоуровневые датчики CPU — температура и мощность — идут через драйвер
PawnIO. Без него эти два показателя могут быть недоступны независимо от прав
запуска; остальное работает.

При первом запуске Traymetry это объясняет и предлагает настройку. Только
после вашего согласия она скачивает официальный подписанный установщик из
GitHub Release PawnIO 2.2.0 и запускает его через UAC. Перед запуском
проверяются закреплённый SHA-256 и сертификат издателя (namazso.eu). Сам
установщик в архив не входит, и для этого одного шага нужен интернет.

Откажетесь — ничего не сломается: потеряете температуру и мощность CPU,
остальное останется. Некоторые машины после установки драйвера просят
перезагрузку.


УПРАВЛЕНИЕ

- F1 открывает справку со всем списком клавиш и жестов.
- Значок % открывает отдельный ползунок прозрачности. Клик вне ползунка или
  клавиша Escape закрывает его.
- Колесо мыши над окном меняет прозрачность без всякого ползунка. Один клик по
  окну нужен, чтобы Windows начала отдавать прокрутку именно ему; у
  закреплённого окна прокрутка до этого клика уходит в то, что под ним.
- Нижняя полоска раскрывает подробную статистику и возвращает прежний размер.
  Двойной клик по окну делает то же самое.
- Пин фиксирует окно и включает клики сквозь него. В закреплённом виде
  остаётся только кнопка пина: левый клик уходит вниз — и по пустому месту, и
  прямо по цифрам, — а правый и средний по-прежнему достаются виджету.
- Треугольник справа сверху прячет окно в область уведомлений.
- Правый клик открывает меню: карточки, графики, цвета, язык, горячие клавиши,
  поверх окон, автозапуск, выход и удаление сервиса.
- Горячие клавиши по умолчанию: Alt+~ закрепить, Alt+H спрятать, F1 справка,
  Escape убрать окно. Любую можно переназначить или сбросить в меню
  «Горячие клавиши».


ОБНОВЛЕНИЯ

Traymetry не устанавливает обновления без разрешения. Не чаще одного раза в
сутки она проверяет GitHub Releases в фоне; ручная проверка есть в меню по
правому клику.

Перед заменой исполняемого файла его SHA-256 сверяется с манифестом релиза,
подписанным ключом проекта, текущий файл сохраняется как резервная копия, а
замена выполняется атомарно. Для обновления сервиса датчиков Windows может
один раз показать UAC.

Стабильная установка следует за стабильными релизами и не берёт предрелизы.
Нужны preview-сборки — поставьте одну вручную со страницы релизов.


ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

- Правый клик → «Собрать отчёт о проблеме…». Файл появится на рабочем столе:
  версия, настройки, состояние датчиков и журнал. Приложите его к issue на
  GitHub.
- Если окно не запускается вообще, тот же отчёт собирается из командной
  строки: Traymetry.exe --report
- Журнал лежит в %LOCALAPPDATA%\Traymetry\traymetry.log


ЕСЛИ ВМЕСТО ТЕМПЕРАТУРЫ ПРОЧЕРК

- завершите Traymetry через правое меню и запустите снова;
- убедитесь, что установка сервиса датчиков была подтверждена;
- если установщик потребовал перезагрузку — перезагрузите Windows;
- если не помогло, сообщите модель CPU/GPU, версию Windows и приложите отчёт.

Если температура видна только при запуске от администратора, выберите в правом
меню «Проверить и починить датчики…» и один раз подтвердите UAC. После этого
Traymetry должна запускаться в обычном режиме.


ЕСЛИ ОКНО РИСУЕТСЯ СТРАННО

Окно использует попиксельную прозрачность — так края цифр остаются чистыми на
любом фоне. Если на вашей видеокарте это выглядит неправильно, запустите с
ключом

   Traymetry.exe --classic

он возвращает старый режим с цветовым ключом. И обязательно сообщите об этом:
ключ существует как запасной выход, а не как настройка, которая кому-то нужна.


КАК УДАЛИТЬ

1. Правый клик по Traymetry → отключите автозапуск, если он был включён.
2. Правый клик → «Удалить системный сервис датчиков…» и подтвердите UAC.
3. Закройте Traymetry и удалите распакованную папку.
4. PawnIO намеренно не удаляется автоматически: его могут использовать другие
   программы. При необходимости удалите его отдельно через параметры Windows.
